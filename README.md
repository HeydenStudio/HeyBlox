### Как подключится к официальным серверам
Скачайте Radmin vpn запустите его после нажмите "Сеть" потом "Присоединится к сети" потом "Частная сеть" И вводите туда в название : "HeyBlox" Пароль "HeyBloxOnline" после скачайте ПОСЛЕДНЮЮ версию HeyBlox запустите его.Нажмите кнопку Versions и выберете версию 2011M если вы хотите поиграть в игры 2011 по 2017 год или другую версию которая написана в #сервера-🌐  после найдите вкладку JoinServer в вкладке "play" в Server IP Adress напишите "26.222.162.192" после зайдите в чат #сервера-🌐  и после в HeyBlox в JoinPort напишите то число которое нужно для захода на сервер. После нажмите Play (не обезательно скачивать саму карту с сайта HeyBlox)

### Как создать свой сервер?
1. Для этого вам нужно скачать саму игру с сайта HeyBlox. 
2. После этого перейти по этой сыллке в прововоднике ( C:\HeyBloxAlpha6\maps\Custom Maps )
3. Перекиньте в эту папку саму игру
4. Зайдите в лаунчер
5. Выберете версию нужную для этого плейса
6. Нажимаете на кнопку Server и делаете host port (условно 2) и нажмите Start server (перед этим в Places выбрав саму игру)
7. После в Radmin vpn вы должны скопировать свой IP
8. Напишите  во вкладе Join Server в 1 строке свой ip 
9. Напишите в JoinPort то что вы написали ранее. Готово вы создали и зашли на свой сервер
(Чтобы поделится сервером с друзьями они должны выполнить 7 и 8 пункт а так же выбрать во вкладе Versions ту версию которую вы выбрали при создании сервера)
